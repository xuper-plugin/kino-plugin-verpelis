# VerPelis

Películas de **verpelis.gratis** en Kino. **Sin torrents**: enlaces de reproducción directa,
resueltos por el plugin **Kino Resolver**.

## Instalar

En Kino, Plugins ▸ Agregar plugin:

```
xuper-plugin/kino-plugin-verpelis
```

La primera vez te pedirá instalar **Kino Resolver** (un toque). Sin él no puede reproducir.
